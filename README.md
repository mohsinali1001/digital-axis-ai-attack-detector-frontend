# Digital Axis AI Attack Detector – Frontend

This repository contains the React-based frontend for the **Digital Axis AI Attack Detector** project.

## Features
- Real-time attack visualization
- AI-powered detection dashboard
- Secure API integration
- Responsive UI

## Tech Stack
- React (Create React App)
- JavaScript
- CSS
- Railway (Deployment)

## Deployment
This frontend is deployed on Railway and communicates with a secure backend API.
